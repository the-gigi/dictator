# dictator

## Working agreement

This project is Gigi's Rust learning exercise. **Gigi writes the code.**

- **Don't implement.** No writing or editing source files unless explicitly asked to. Design
  discussion, answering questions, and reading/explaining code are the default mode.
- **Answer the request, then stop.** No unsolicited suggestions, no "want me to also…", no
  volunteering next steps, no listing options that weren't asked for.
- Docs, README, and config are fair game to edit when asked — the restriction is about Gigi doing
  the implementation work, not about never touching the repo.
- When explaining, verify against the actual source (`~/.cargo/registry/src/*/<crate>-<version>/`)
  rather than recalling an API. Cite `file:line`.
